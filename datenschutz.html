Das Programm Knips

Knips verarbeitet deine Screenshots ausschließlich auf deinem eigenen Rechner: Aufnehmen, Markieren, Unscharf machen, Texterkennung (über die in Windows eingebaute Texterkennung) und das Archiv im Ordner „Bilder“. Dabei werden keine Bilder, Texte oder sonstigen Inhalte an mich oder an Dritte übertragen.

Update-Prüfung: Damit du Verbesserungen automatisch bekommst, fragt Knips etwa einmal am Tag bei GitHub nach, ob es eine neuere Version gibt (Abruf einer kleinen Datei mit der Versionsnummer). Dabei erhält GitHub technisch bedingt deine IP-Adresse. Es werden keine weiteren Daten über dich oder deine Nutzung gesendet. Nur wenn du auf „Jetzt aktualisieren“ klickst, wird die neue Setup-Datei von GitHub heruntergeladen.
